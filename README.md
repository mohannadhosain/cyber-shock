# CYBER SHOCK 3.0 — THE BLACKOUT

موقع عربي ثابت لمحاكاة توعوية سينمائية لتأثير الهندسة الاجتماعية والإنذارات الأمنية على قرارات المستخدمين.

## التشغيل

افتح `index.html` في متصفح حديث، أو انشر الملفات الثلاثة (`index.html` و`styles.css` و`app.js`) على GitHub Pages.

## النشر على GitHub Pages

1. انتقل إلى Settings ثم Pages في المستودع.
2. تحت Build and deployment اختر Deploy from a branch، ثم main و /(root) واحفظ.
3. الرابط الخاص بهذا المستودع هو https://mohannadhosain.github.io/cyber-shock/
4. افتح الرابط واختبره ثم أنشئ رمز QR منه.

## اعتبارات مهمة

- الموقع مستقل، ولا يحتاج إلى لوحة مدرب أو حسابات أو خادم أو قاعدة بيانات.
- يستطيع نحو 30 مشاركاً فتح الصفحة، ويبدأ العرض محلياً بعد ضغط زر البدء لكل مشارك؛ لا توجد مزامنة بين الهواتف.
- يبدأ العرض بموافقة صريحة عامة على تمرين توعوي يتضمن تنبيهات ومؤثرات.
- لا يوجد وصول للكاميرا أو الميكروفون أو الموقع أو الملفات ولا طلب كلمات مرور.
- يمكن للمشارك إنهاء العرض في أي وقت، ولا يُمنع إغلاق المتصفح.
- يستورد CSS خطوط Cairo وIBM Plex Mono من Google Fonts.
- النص النهائي يوضح بالعربية أنه لم يحدث أي اختراق للهاتف.

## الملفات

- `index.html`: واجهة البداية والموافقة.
- `styles.css`: الهوية البصرية والمؤثرات.
- `app.js`: تسلسل المشاهد والتوقيت والكشف النهائي.

استخدمه كتدريب توعوي بموافقة المشاركين وليس إشعاراً حقيقياً عن اختراق أجهزة.
